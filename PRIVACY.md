# Memory Stack Privacy Policy

Memory Stack uses an email address only when the user chooses cloud authentication through Supabase. Solved-problem, revision, performance, and memory-strength data is stored locally in demo mode and in the user's protected Supabase account when cloud mode is configured. Row-level security prevents users from reading another user's data.

The app does not sell or share personal data. AI requests contain the problem title and difficulty, not account credentials. Notifications may be disabled in device settings. Users can request account deletion through the support contact configured for their published store listing.

Last updated: August 1, 2026.
